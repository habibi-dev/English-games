# English Grammar Quest

بازی تمرین گرامر انگلیسی به صورت PWA. سؤال‌ها از «بانک سؤال» خوانده می‌شوند و بازی خودش سؤال نمی‌سازد.

## ساختار پوشه‌ها

| مسیر | کاربرد |
| --- | --- |
| `banks.json` | فهرست بانک‌های سؤال. هر بانک یک فایل JSON است. |
| `banks/` | فایل‌های JSON بانک‌های سؤال. هر فایلی که اینجا باشد و در `banks.json` ثبت شود، بارگذاری می‌شود. |
| `js/` | کد برنامه (بدون مرحله‌ی build). |
| `css/`, `index.html`, `sw.js`, `manifest.webmanifest` | ظاهر و PWA. |
| `tests/` | تست‌های واحد (`npm test`). |
| `tools/` | اسکریپت‌های کمکی (مثلاً ساخت بانک مبتدی). |

## اجرا

**با داکر (پیشنهادی):**

```
docker compose up -d --build
```

سپس `http://localhost:8080` را باز کن.

**بدون داکر:** پوشه‌ی پروژه را با هر سرور استاتیک اجرا کن، مثلاً:

```
python -m http.server 8080
```

## افزودن یک بانک سؤال جدید

۱. فایل JSON بانک را در پوشه‌ی `banks/` بگذار. ساختار فایل:

```json
{
  "schema_version": "1.1",
  "dataset_name": "نام بانک",
  "questions": [
    {
      "id": "x001",
      "category": "quick_translation",
      "topic": "to_be",
      "difficulty": "easy",
      "question": "من معلم هستم.",
      "expected_answer": "I am a teacher.",
      "accepted_answers": ["I am a teacher."],
      "explanation": "برای I از am استفاده می‌کنیم.",
      "glossary": [{ "word": "teacher", "meaning": "معلم" }],
      "points": 10,
      "time_limit": 25,
      "enabled": true
    }
  ]
}
```

- `id` باید در کل بانک‌ها یکتا باشد. شناسه‌ی تکراری در یک فایل رد می‌شود.
- `category` یکی از این‌هاست: `quick_translation`، `sentence_builder`، `grammar_correction`، `multiple_choice`، `positive_negative_question`، `voice_translation`.
- برای `sentence_builder` فیلد `word_bank` و برای `multiple_choice` فیلد `options` لازم است. برای `grammar_correction` فیلد `incorrect_sentence` لازم است. جزئیات را در `js/bank/schema.js` ببین.

۲. یک ورودی به `banks.json` اضافه کن:

```json
{
  "id": "my-bank",
  "name": "نام نمایشی بانک",
  "file": "banks/my_bank.json",
  "version": "1",
  "default": false
}
```

- `id` یکتا باشد و در پوشه‌ی سؤال‌ها به برچسب بانک تبدیل می‌شود.
- `file` مسیر فایل نسبت به ریشه‌ی سایت است (با `banks/` شروع شود).
- `default: true` یعنی این بانک در تنظیمات بازی از اول انتخاب باشد.

۳. برنامه را دوباره بساز و اجرا کن:

```
docker compose up -d --build
```

۴. صفحه‌ی برنامه را باز کن. بانک جدید خودکار بارگذاری می‌شود و پیامی مثل «N سؤال از بانک‌های جدید بارگذاری شد» نشان داده می‌شود. در صفحه‌ی **بازی** بانک جدید در فهرست «بانک سؤال» ظاهر می‌شود.

## به‌روزرسانی یک بانک موجود

تغییر در فایل JSON یک بانک به‌تنهایی روی دستگاه‌ها اعمال نمی‌شود. برای اعمال تغییرات:

۱. فایل JSON را تغییر بده (سؤال اضافه، حذف یا ویرایش).
۲. در `banks.json`، مقدار `version` همان بانک را عوض کن (مثلاً از `"1"` به `"2"`).
۳. `docker compose up -d --build` را اجرا کن و صفحه را باز کن.

وقتی `version` یا مسیر `file` تغییر کند، برنامه آن بانک را دوباره بارگذاری می‌کند:

- سؤال‌های همان فایل به‌روز می‌شوند (با همان `id` بازنویسی می‌شوند).
- سؤال‌هایی که از فایل حذف شده‌اند، از دستگاه هم حذف می‌شوند.
- **تغییرات دستی همان بانک در بخش مدیریت سؤال‌ها با این کار بازنویسی می‌شوند.** اگر می‌خواهی ویرایش دستی بماند، آن را در فایل JSON هم اعمال کن.
- سؤال‌های اضافه‌شده‌ی دستی (بدون برچسب بانک) تغییر نمی‌کنند.

اگر می‌خواهی همه‌ی بانک‌ها یک‌جا از فایل‌ها دوباره خوانده شوند، در بخش **بانک سؤال** از دکمه‌ی «بازگردانی از فایل‌های بانک» استفاده کن.

## خطاهای بارگذاری

- سؤال‌های نامعتبر گزارش می‌شوند و بقیه‌ی سؤال‌ها بارگذاری می‌شوند. جزئیات در کنسول مرورگر (`console`) و در بخش **بانک سؤال** دیده می‌شود.
- اگر فایل یک بانک پیدا نشود یا JSON خراب باشد، فقط همان بانک خطا می‌دهد و بانک‌های دیگر بارگذاری می‌شوند.
- اگر بانکی را از `banks.json` حذف کنی، سؤال‌های آن از دستگاه پاک نمی‌شوند و چک‌باکس بانک هم در تنظیمات می‌ماند. برای غیرفعال کردن موقت، چک‌باکس آن را در تنظیمات بازی بردار.

## تست‌ها

```
npm test
```

برای اجرای تست‌ها داخل داکر:

```
docker build --target test -t english-grammar-quest:test .
```

## استقرار

ایمیج داکر فقط فایل‌های استاتیک را سرو می‌کند. فایل‌های JSON و JS و CSS همیشه از سرور تازه گرفته می‌شوند (`no-cache`)، پس بعد از هر بار `up --build` نسخه‌ی جدید به کاربران می‌رسد.
